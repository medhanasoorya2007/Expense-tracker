# Expense Tracker (MERN)

## Features
- User Authentication (JWT)
- Add/Edit/Delete Income
- Add/Edit/Delete Expenses
- Dashboard Analytics
- Charts
- Excel Export
- Responsive UI

## Tech Stack
Frontend:
- React
- Vite
- Axios
- React Router

Backend:
- Node.js
- Express
- MongoDB
- JWT
- Mongoose

## Installation

Frontend

npm install
npm run dev

Backend

npm install
npm start
